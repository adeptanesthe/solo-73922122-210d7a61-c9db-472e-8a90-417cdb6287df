# 野生动物追踪串号校正与计数台

面向野生动物视觉工程师的网页工具：纠正追踪串号（ID switch）造成的漏计 / 重复计数。
上传帧图片与检测框，标记“同只 / 异只”判断，调整关联代价参数，求解**全局最小**关联，
按轨迹条数给出动物计数；判断冲突时明确提示无解，不给计数。

此外提供**相邻帧背景配准**：复核相邻相机帧中的动物位移时判断镜头是否抖动。
以当前帧和下一帧为一组，仅用检测框外的背景像素估计 ±16 像素内的整数平移，
展示位移与对齐后的半透明叠图；无法可靠配准时明确说明原因，不显示位移及叠图。

## 使用流程

1. **数据**：上传 1~10 张帧图片 + 1 个检测 JSON（≤30 框），或点击“加载交叉遮挡示例”。
2. **按帧查看与标记**：←/→ 键或按钮切换帧；点击两个检测框（可跨帧）后选择
   “标记为同只 / 异只”，可随时清除。
3. **代价参数**：距离权重、外观权重、每条新轨迹罚分，均可调。
4. **求解**：点击“计算最优关联”。计算期间可继续修改判断与参数；
   任何修改会立即撤下旧结果，迟到的旧结果不会覆盖新输入（按输入版本号校验）。

## 检测 JSON 格式

```json
{
  "detections": [
    {"id": "b1", "frame": 0, "rect": [x, y, w, h], "vector": [0.8, 0.1, 0.2]}
  ]
}
```

- `id`：框号（字符串或数字，全局唯一）
- `frame`：帧号，0 起，须小于上传图片数
- `rect`：`[x, y, 宽, 高]`，宽高为正
- `vector`：非零外观向量，所有框维度一致（≤512 维）

会话内可下载当前检测 JSON：`GET /api/sessions/{sid}/detections.json`。

## 模型与求解

- 约束：每框恰属一条轨迹；同一轨迹每帧至多一框；轨迹内相邻框帧差 1~2 且时间递增。
- 关联代价：`w_dist × 框中心距离平方 + w_app × (1 − 余弦相似度)`。
- 目标：所有关联代价 + 轨迹条数 × 新轨迹罚分，求**全局最小**。
- 方法：整数线性规划（SciPy `milp` / HiGHS）。
  “同只”用单位流强制可达（同轨迹），“异只”用 0/1 割变量强制不可达。
- 判断相互冲突（如两框同帧却标同只、同只与异只传递冲突）时返回**无解**，
  界面明确提示且不显示动物计数。
- 动物数 = 轨迹条数。

## 内置交叉遮挡示例

6 帧画面：A（红）与 B（蓝）沿 X 形路径相向穿行，第 3 帧 B 被 A 遮挡缺失检测、
A 的外观向量被污染。正确结果为 2 条轨迹（2 只）：B 链需跨 2 帧连接（帧 2→帧 4），
遮挡点两侧两框位置极近，朴素最近邻会在交叉点串号。
默认参数（w_dist=1、w_app=10000、罚分=15000）针对该示例调优；
上传自有数据时请按图像尺度与外观向量区分度调整权重。
示例背景含帧间位置固定的地物，因此相邻帧配准应稳定得到 (0, 0)，可直接观察叠图效果。

## 背景配准（镜头抖动判断）

在“按帧查看”区域，载入会话或切换帧时会自动对**当前帧与下一帧**发起配准，
也可点击“重新估计”。最后一帧没有下一帧，不做配准。

### 算法

1. 两帧均用 Pillow 解码为灰度图；解码失败、尺寸不一致或任一边长超过 512 像素
   直接判为无法配准。
2. 把两帧的**检测矩形各向外扩 6 像素**合并为掩膜：任一帧落在检测框内的像素
   都不参与匹配，避免移动的动物干扰背景估计。
3. 画面均分为 4×4 个候选背景块，每块在 ±16 像素搜索窗内做**掩膜归一化互相关
   （NCC）**，由 `scipy.signal.fftconvolve` 加速。块内背景像素过少、灰度标准差
   过低（纹理不足）、相关峰过低或最优/次优峰差距过小（峰不锐）的块记为不可信。
4. 至少 **3 个分散**（覆盖 ≥2 个网格行且 ≥2 个网格列）的可信块指向同一位移才接受；
   另有可信块指向不同位移（区域分歧），或全局最优/次优位移的平均相关分差距过小
   （可信度相近的不同位移）时判为无法可靠配准。
5. 配准成功返回整数位移 `(dx, dy)`：把下一帧整体平移该像素数即与当前帧背景对齐；
   叠图为 0.5·当前帧 + 0.5·平移后下一帧，平移越界处保留当前帧原色。

### 不可靠情形（不显示位移及叠图）

| reason_code | 含义 |
| --- | --- |
| `decode_error` | 图片无法解码 |
| `size_mismatch` | 两帧尺寸不同 |
| `too_large` | 边长超过 512 像素 |
| `insufficient_background` | 检测框外背景像素占比过低 |
| `insufficient_texture` | 纹理充足且可信的分散背景区域不足 3 处 |
| `regions_disagree` | 不同背景区域指向不同位移 |
| `ambiguous` | 存在可信度相近的不同位移 |

配准与会话输入版本绑定，且前端用单调递增的请求令牌（regToken）守卫：
切帧或换会话立即撤下旧配准，在途的迟到结果不会覆盖当前画面。
配准是独立功能，不影响原有轨迹求解与动物计数。

## API 摘要

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/sessions` | 上传图片（`images`）+ 检测 JSON（`detections`），创建会话 |
| POST | `/api/example` | 创建交叉遮挡示例会话 |
| GET | `/api/sessions/{sid}` | 会话数据（含输入版本号） |
| GET | `/api/sessions/{sid}/frames/{i}` | 第 i 帧图像 |
| PUT | `/api/sessions/{sid}/judgments` | 整体替换同只/异只判断（版本 +1） |
| PUT | `/api/sessions/{sid}/params` | 更新代价参数（版本 +1） |
| POST | `/api/sessions/{sid}/solve` | 启动异步求解，返回任务 id 与输入版本 |
| GET | `/api/jobs/{job_id}` | 查询求解状态与结果（结果携带输入版本） |
| POST | `/api/sessions/{sid}/registration` | 启动相邻帧背景配准，body 为 `{"frame": i}` |
| GET | `/api/registration-jobs/{job_id}` | 查询配准状态；成功时含 `dx`/`dy` 与 base64 叠图，失败时含原因码且无叠图 |

## 说明与限制

- 会话与任务保存在进程内存中，重启即清空（单用户工具定位）。
- 上限：10 帧、30 框、200 条判断、外观向量 512 维。
- 背景配准仅处理宽高均 ≤512 且尺寸相同的图片，搜索范围 ±16 像素、整数平移；
  512×512 图片单次配准通常在 1 秒内完成。
- 求解默认 60 秒时限；本规模（≤30 框）通常在毫秒级完成。
